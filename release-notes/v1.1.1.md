# v1.1.1：保守兼容版

这是 Do3Think USB3 12M ASCOM 驱动的保守回退安装包。

## 与 v1.1.2 的检查结果

- 两个发布压缩包中的 ASCOM Platform 组件、`DVPCameraCS.dll` 和配置文件完全相同。
- 只有主驱动 `ASCOM.RobertDo3Think_USB3_12M_Camera.exe` 不同：v1.1.1 为 95,744 字节，v1.1.2 为 94,720 字节。
- v1.1.1 的采集错误恢复路径包含“先停止/重新启动采集流，失败后再关闭并重新打开相机”。v1.1.2 调整了这条路径，移除了前面的独立流恢复步骤，并改动了采集循环、帧检查、参数应用和重连逻辑。

因此，v1.1.1 更适合作为已经验证过的系统的保守稳定版本；如果 v1.1.2 在某些 USB、曝光切换或重连场景下出现异常，可以先回退到 v1.1.1。这里的“更稳定”是基于改动范围和兼容性风险的发布建议，并不是对所有硬件环境的绝对保证。

## 安装包校验

文件：`RobertDo3Think_ASCOM_Camera_Driver_Setup_1.1.1.exe`

SHA-256：

```text
261DC295A644A8379B45C5F5832C0493A26C7EA532C4F899242ECF98074A2C4A
```

安装程序会自动注册 ASCOM 驱动；卸载时会自动注销驱动。使用前请确保已安装 ASCOM Platform，并保持 Do3Think 相机的 USB3 连接和 SDK 运行环境正常。
